让月光使用微软正版身份

月光已加入微软网页授权、Xbox 身份验证、Minecraft Java 资格检查、账号切换和凭证刷新。启用前，需要为月光配置自己的微软应用编号，并获准访问 Minecraft 游戏服务。

当前状态：功能已做好，应用编号尚未配置。
本版本没有附带其他启动器的 Client ID。尚未完成真实微软账号登录或正版服务器联机验证。已有游戏、整合包与离线单人模式可继续使用。

1. 注册月光自己的应用

  1. 按微软的应用注册说明，进入 Microsoft Entra 的「应用注册」，新建用于月光的应用。需要有权注册应用的微软目录；如果个人账号没有目录权限，须先按微软当前要求取得注册权限。
  2. 支持的账号类型选择包含个人 Microsoft 账号的选项。月光使用个人账号登录端点，不支持仅工作或学校账号的应用。
  3. 在「身份验证」的高级设置中，开启 Allow public client flows / 允许公共客户端流并保存。月光使用设备登录码流程，不要求回调网址，也不需要创建客户端密钥。
  4. 在应用概述页复制 Application (client) ID / 应用程序（客户端）ID。它是形如 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx 的公开编号，不是目录 ID、对象 ID 或账号密码。

2. 申请 Minecraft 接口许可

注册微软应用与获得 Minecraft 接口许可是两个步骤。请查看 Minecraft 应用注册说明，或在官方 Java Edition 帮助中心查找「Java Edition Game Service API Review or Application Process」。按官方当前要求提交应用编号、用途和所需资料。

打开 App ID 审核申请入口。表单和要求可能调整，请以官方页面为准。审核是否通过及耗时由微软 / Mojang 决定。只填写编号不代表已获准访问接口；未获准时，Minecraft 登录可能返回 403。

3. 在月光中填写编号

  1. 打开月光，进入设置 → 游戏身份与登录 → 配置微软登录，或点击「应用配置…」。
  2. 粘贴获准应用的 Client ID，点击「保存配置」。格式检查只检查编号是否有效，接口许可会在实际登录时检查。
  3. 点击「添加微软账号」。月光会打开微软网页，并显示一个短登录码。复制登录码，在微软网页输入；确认网页显示的授权应用与你注册的应用一致，再登录并授权。
  4. 保持月光打开。通过 Xbox 和 Minecraft Java 资格检查后，角色会出现在账号列表中，月光自动选择该账号并切换为「微软正版」。返回首页启动游戏即可。

账号必须具有有效的 Java 版游戏资格，并完成 Java 角色名称设置。登录其他账号后可点击「使用此账号」切换。服务器还可能要求白名单、指定版本或相同模组；正版身份验证成功不代表能加入所有服务器。

凭证如何保存

密码只在微软网页输入。月光将刷新凭证和 Minecraft 登录凭证保存在本机 macOS 钥匙串中；普通设置文件只记录应用编号、角色名和角色 UUID。启动正版游戏前会检查资格，必要时刷新登录。验证失败会停止启动并显示原因；若要离线游玩，请自行切换「离线单人」。

「退出登录」删除此账号在月光中的本地凭证，不会退出浏览器中的微软账号，也不会注销其他设备。若需撤销应用授权，请前往微软账号的应用权限管理。升级本地签名的月光后，macOS 可能再次请求钥匙串访问许可。

遇到问题

  • 没有应用编号：先完成注册和接口审核；当前可继续使用离线单人。
  • 微软应用配置未通过：检查是否复制了正确 Client ID、是否支持个人账号、是否已开启公共客户端流程。
  • Minecraft 返回 403：检查应用接口许可与账号限制。反复登录无法替代应用审核。
  • 没有 Java 版资格：确认登录了持有 Java 版的微软账号；仅有其他版本或过期订阅可能不满足条件。
  • 需要 Xbox 档案 / 家长授权：按界面提示在 Xbox 或微软家庭设置中完成，再重新登录。
  • 登录码过期或取消：重新点击登录，使用新登录码。无需向任何人提供登录码或令牌。
  • 钥匙串不可访问：解锁 macOS 登录钥匙串并允许月光访问；仍失败时重新添加账号。

开发配置

界面配置优先于环境变量 MOONLIGHT_MICROSOFT_CLIENT_ID，再优先于应用 Info.plist 中的 MoonlightMicrosoftClientID。已有账号刷新时始终使用最初登录所属的应用编号。更换编号后，应重新添加账号。

打包时可设置同名环境变量，将已批准的编号写入应用。未设置时，构建不附带默认编号。不要使用其他启动器的应用编号，也不要将客户端密钥、密码或登录令牌写入配置。

配置说明更新于 2026-10-11。登录流程使用微软设备授权协议。已通过模拟协议、启动身份与本机钥匙串存取测试；真实服务登录及联机仍待获准应用编号后验证。月光是独立启动器，与 Microsoft / Mojang 无隶属关系。
